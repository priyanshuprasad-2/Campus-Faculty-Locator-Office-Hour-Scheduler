# Campus Faculty Locator & Office Hour Scheduler

A Python-based project designed to help students locate faculty members, check their cabin details, and find suitable meeting times.

## Features

- **Student Portal:** Search for faculty details and check their availability.
- **Faculty Portal:** Register faculty names, cabin details, and available time slots.
- **Program Coordinator Portal:** View student interaction history and query resolution status.
- **Email Authentication:** Separate access for students, faculty, and program coordinators using Bennett email domains.
- **Availability Checker:** Check whether faculty members are available at the requested time and suggest the next available slot.
- **File Handling:** Store faculty details and student interaction records in text files.

## Technologies Used

- Python
- File Handling
- Functions
- Conditional Statements
- Loops
- String Manipulation

## How to Run

1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open the project folder in the terminal.
4. Run:

```bash
python "Campus Faculty Locator & Office Hour Scheduler.py"
```

5. Follow the instructions displayed in the terminal.

## Data Files

The program automatically creates the following files:

- `students.txt` – Stores student interaction records.
- `teachers.txt` – Stores faculty details and availability.
